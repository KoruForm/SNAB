# Landing page artwork

`good-finds.png` is the AI-generated editorial image approved in the SNAB mobile design concept. It illustrates secondhand finds on the landing page and must not be used as the photograph of an actual sale or listing. The landing page does not overlay a sticker or label on the artwork.

`good-finds-tab.png` is the same image with extra wall added above it (the top row of pixels repeated), so the folder-tab photo shape (`/brand/photo-tab.svg`) can cut the top edge without clipping the lamp. The landing hero uses this version.
